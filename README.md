# まどぴた

画像を読み込み、移動・拡大・90度回転して125 × 70mmに切り抜くブラウザツールです。画像は端末内で処理します。外部通信はGoogle Fontsの読み込みのみで、画像の送信はありません。

## コンビニの写真用紙で使う

1. 画像を読み込み、切り抜く位置を調整します。実効ppiと切り抜き元の画素数で画質を確認できます。画質優先ならスクショより元画像を使い、過度な拡大を避けてください。
2. 「2L写真プリント用JPEGを保存」。初期値は600dpi（4205 × 3000px）。300dpi（2102 × 1500px）にも対応します。JPEGのJFIFにも解像度を記録します。最大9.9MB未満になるまでJPEG品質を0.98→0.95→0.92と調整し、それでも大きい場合は保存せず300dpiへの変更を案内します。
3. スマホのダウンロード先から印刷アプリへ登録します。必要ならファイルを開いて写真アプリにも保存してください。写真プリントの「2L判」を選択。アプリ側でズーム・トリミング・白フチ追加・フレーム加工をしないでください。
4. 初回は1枚試し刷りし、100mm確認線と縦横の裁断寸法を確認します。サイズがずれている場合、「試し刷り後のサイズ補正」に**補正なしで印刷した100mm線の実測値**を入力し、同じ印刷設定で再保存・再印刷します。倍率を100 / 実測値で補正します。補正値はJPEG用のみ。縦横で異なる倍率のずれや色味は補正しません。別の印刷設定に変えるときは補正を解除して測り直してください。
5. 四隅の裁断目印を結ぶ位置で134 × 82mmに切ります。目印・確認線は切り落とす部分にあり、画像内には窓・安全範囲ガイドを焼き込みません。

2L判は178 × 127mm。補正なしでは用紙を中央（左22mm・上22.5mm）に置き、その中の左5mm・上10mmに画像を配置します。L判（127 × 89mm）には134mmの用紙が収まりません。写真プリントには周囲のカット・拡大縮小が入る場合があるため、初回から厳密な実寸は保証できません。実機印刷は未検証です。

公式案内：[セブン‐イレブン](https://www.printing.ne.jp/support/landing/landing_smartphone_picture.html)、[フォト用紙のJPEG・容量制限](https://www.printing.ne.jp/support/lite/attention_lite.html)、[ネットワークプリント](https://networkprint.ne.jp/)。店舗・機器・登録経路によって設定や対応が異なります。

- 切り抜きPNG：125 × 70mm、300 / 600dpi（整数ピクセルへの丸めあり、PNGのpHYsに解像度を記録）
- 実寸PDF：134 × 82mm用紙、画像を左5mm・上10mmに125 × 70mmで配置
- 透明窓：124 × 69mm（画像周囲0.5mm）
- 推奨範囲：120 × 65mm（中央配置）
- マウス・タッチで移動、ホイール・ピンチ・スライダーで拡大。矢印キーで位置調整、Shiftで大きく移動。

印刷時はPDFを使用し「実際のサイズ / 100%」で印刷してください。家庭用プリンターでは小さい用紙や2mmの下余白に対応しない場合があります。大きい用紙に100%で印刷して134 × 82mmに裁断する方法も使えます。

ビルド不要。`index.html`を開くか、静的HTTPサーバーで配信してください。GitHub Pagesはmainブランチのルートを配信します。
