# まどぴた

画像を読み込み、移動・拡大・90度回転して125 × 70mmに切り抜くブラウザツールです。画像は端末内で処理します。外部通信はGoogle Fontsの読み込みのみで、画像の送信はありません。

- 切り抜きPNG：125 × 70mm、300 / 600dpi（整数ピクセルへの丸めあり、PNGのpHYsに解像度を記録）
- 実寸PDF：134 × 82mm用紙、画像を左5mm・上10mmに125 × 70mmで配置
- 透明窓：124 × 69mm（画像周囲0.5mm）
- 推奨範囲：120 × 65mm（中央配置）
- マウス・タッチで移動、ホイール・ピンチ・スライダーで拡大。矢印キーで位置調整、Shiftで大きく移動。

印刷時はPDFを使用し「実際のサイズ / 100%」で印刷してください。家庭用プリンターでは小さい用紙や2mmの下余白に対応しない場合があります。大きい用紙に100%で印刷して134 × 82mmに裁断する方法も使えます。

ビルド不要。`index.html`を開くか、静的HTTPサーバーで配信してください。GitHub Pagesはmainブランチのルートを配信します。
